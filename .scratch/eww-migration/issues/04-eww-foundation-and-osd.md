# 04: eww の基盤と OSD

**What to build:** eww を導入し、最初の部品として OSD を動かす。

- **キー操作と OSD**: 音量キー（上げる、下げる、ミュート）と輝度キー（上げる、下げる）を押すと値が変わり、画面下の中央に OSD が出る。OSD にはアイコン、ゲージ、% を表示する。ミュート中はアイコンを変え、ゲージを灰色にする。最後にキーを押してから約 1.5 秒で消え、連打している間は表示し続ける（消えるまでの時間を延長する）。OSD はフォーカスを取らない。キー操作以外で値が変わったときは OSD を出さない。
- **基盤**: 新しい denix モジュール `programs.eww` を作り、`features.gui` から有効にする。
  - eww のデーモンは systemd で起動する（`graphical-session.target` に紐づける）。
  - yuck、scss、スクリプトはリポジトリ内の普通のファイルとして置き、Nix ストア経由で配置する。
  - 02 で作った配色生成器に、eww 用の SCSS 変数ファイルの出力を足す。
  - ホストごとの差分（輝度とバッテリーを出すか、つまり `hardware.laptop` が有効かどうか）を、eww から読めるファイルとして Nix で生成する。
- **スクリプト**: OSD 用のスクリプトは bash と jq で書き、`writeShellApplication` でパッケージにする（依存は `runtimeInputs` で固定する）。niri の音量キーと輝度キーはこのスクリプトを呼ぶように付け替える。
- **見た目と操作の方針**: フォントは ZedMono Nerd Font にする。マウスで反応する部品は作らない（ADR-0002）。

参照: spec.md の「OSD」（ユーザーストーリー 46〜54）、「eww」、ユーザーストーリー 25〜26、64〜68。
