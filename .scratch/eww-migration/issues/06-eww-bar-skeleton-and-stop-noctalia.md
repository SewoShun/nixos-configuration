# 06: eww のバー（骨格、ワークスペース、日付と時刻）と Noctalia の起動停止

**What to build:** すべてのモニターの左端に eww の縦置きのバーを出し、画面の領域を予約して、ウィンドウがバーに重ならないようにする。同じ変更で、niri の起動処理から Noctalia を外し、バーが二重に出る期間を作らない。

バーには上から次のものを並べる。

- **ワークスペース**: そのバーが乗っているモニターのワークスペースだけを番号で並べる。アクティブなものを強調し、ウィンドウがあるかどうかで見た目を変える。niri のイベントストリームを購読するスクリプト（bash と jq、`writeShellApplication`）で、変化にすぐ追従させる。
- **日付と時刻**: カレンダーのアイコン、月、日、時計のアイコン、時、分の順に縦に並べる。文字の大きさと色はすべて同じにする。

バーのウィンドウは、Nix が生成したモニターの一覧をもとにモニターごとに作り、eww サービスの起動直後（`ExecStartPost`）に開く。デーモンが再起動しても（クラッシュ、switch）バーが開き直される。マウスで反応する部品は作らない（ADR-0002）。

参照: spec.md の「バー（共通）」「バー：ワークスペース」「バー：日付と時刻」（ユーザーストーリー 20〜34）。
