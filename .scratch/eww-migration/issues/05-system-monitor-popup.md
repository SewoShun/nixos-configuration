# 05: システムモニターのポップアップ

**What to build:** `Mod+Shift+m` で、eww のシステムモニターのポップアップを開閉できるようにする。ポップアップには CPU 使用率、メモリ、ディスク、温度を、eww の組み込み変数を使って表示する。ポップアップはフォーカスを取らず、同じキーをもう一度押すと閉じる。配色とフォントはバーや OSD と揃える。マウスで反応する部品は作らない。

参照: spec.md の「ポップアップ」（ユーザーストーリー 55〜59）。
