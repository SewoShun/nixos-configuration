# 07: バーの状態表示（音量、輝度、バッテリー、ネットワーク）

**What to build:** バーの日付と時刻の下に、上から次の状態表示を足す。

- **音量**: 音量とミュート状態を表示する。PipeWire の変化を購読して、キー操作以外で変えた場合も追従する。
- **輝度**: laptop だけに表示する。
- **バッテリー**: laptop だけに表示する。アイコンと残量の % を出し、充電中は別のアイコンにする。
- **ネットワーク**: 有線、Wi-Fi の電波強度の段階、切断のいずれかを、アイコンだけで表示する（SSID は出さない）。

輝度とバッテリーを出すかどうかは、04 で生成したホストごとの差分ファイルで決める。スクリプトは bash と jq で書き、`writeShellApplication` でパッケージにする。

参照: spec.md の「バー：音量・輝度・バッテリー・ネットワーク・トレイ」（ユーザーストーリー 35〜42）。
